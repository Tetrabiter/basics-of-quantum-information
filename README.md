# Common Operations

1. H Hadamard Создаёт суперпозицию из базисного состояния
2. Y Pauli-Y Меняет базисные состояния с добавлением фаз
3. S Phase gate Изменяет относительную фазу на \(\pi/2\)
4. T T gate Изменяет относительную фазу на \(\pi/4\)
